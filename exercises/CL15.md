## Introduction

The package ggplot2 is based on the grammar of graphics ([Wilkinson 2025](https://doi.org/10.1007/978-3-642-21551-3_13)), which is a series of “rules” for creating virtually all graphical forms. It takes a layered approach to creating visualizations. The basic format involves specifying data, aesthetic mapping (i.e., how variables will be represented in the visual space), a coordinate system, and various layers including "geoms" (visual objects), scales, and so forth. In this lab, we will focus on using ggplot2 to create four types of graphs: a histogram, a scatter plot, a bar plot, and a box plot. However, ggplot2 can be used create numerous other types of graphs, such as density plots, box plots, violin plots, maps, and much more. The lesson will demonstrate the “layered” approach by beginning with the simplest form of a graph and then enhancing it with various changes to the code.

asv_normalized_counts <- read.table("ASVs_normalized.tsv", sep = "\t", header = T)

## Histogram

Create a basic plot that only contains the data and the aesthetic mappings. Note that nothing will be displayed because you have not specifed what type of plot you are creating; however, this step can save you a bit of time later:

```R
ggplot(data = asv_long, mapping = aes(x = Normalized_count))
```

The next step is to add the geom layer. In ggplot2, layers are added with a `+`:

```R
ggplot(data = asv_long, mapping = aes(x = Normalized_count)) +
  geom_histogram()  
```

Adding the geom layer calls a histogram on the variable `Normalized_count`, which was specifed as "x" in the previous call. Note that, because the normalized counts vary a lot, the distribution is skewed heavily to the left. We can do a log-transformation to fix it:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram()  
```

You can change the appearance of the distribution by adding an argument within `geom_histogram()`. There are two options. First, change the number of bins: 

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(bins = 10)
```

This will adjust the number of bins into which the data are sorted. Alternatively, change the bin width, relative to the scale of the x-axis:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1)
```

This will adjust the width of the bins. Practice varying the number of bins or bin width until you find one that you like best. The default color in ggplot2 is gray, but you shouldn't be limited to that! To search for other R colors go [here](https://r-charts.com/colors). Change the color of the bars to the color you want:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "blue")
```

Note that the argument `fill = "blue"` will make both the bars and their borders blue. However, you may want to make the bars and their borders diferent colors for emphasis:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "blue", color = "black")
```

Try adding a hex code instead of a color name. You can use [this resource](https://htmlcolorcodes.com) for hexcodes:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black")
```

Sometimes you will want to modify the limits of the x and/or y axes. This is a somewhat imprecise process for histograms, but the following example shows how to accomplish this. Keep in mind that the number/width of bins will contribute to how R organizes the x axis. In this example, you will set the lower limit of the x axis to NA, which tells R to set the lower limit according to the data. However, you will set the lower limit of y to 0:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600)
```

To add a title use the `ggtitle()` function:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Distribution of Normalized Counts (Log10 Transformed)")
```

By default, ggplot2 uses the variable names as x and y axis labels. Use the `labs()` function to change these:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Distribution of Normalized Counts (Log10 Transformed)") +
  labs(x = "Normalized Counts (Log10)", y = "Frequency") 
```

With a bit of tweaking to the title, you can remove the now-redundant x and y axis labels. Accomplish this by specifying the element_blank() function:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank())
```

You can add notes to parts of the plot by specifying the text and coordinates using the `annotate()` function:

```R
ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 3), y = c(100, 100), label = c("Rare", "Abundant"))
```

The ggplot2 package contains several “themes” that allow for quick alterations to the default plot. Try modifying the plot you have just created by adding the `theme_classic()` layer:

ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 3), y = c(100, 100), label = c("Rare", "Abundant"))+
  theme_classic()

Feel free to try other themes. Learn more about them [here](https://ggplot2-book.org/themes.html).

Save the final plot as `asv_histogram`:

```R
asv_histogram <- ggplot(data = asv_long, mapping = aes(x = log10(Normalized_count))) +
  geom_histogram(binwidth = 0.1, fill = "0099F8", color = "black") +
  xlim(NA, 3) + ylim(0, 600) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 3), y = c(100, 100), label = c("Rare", "Abundant"))+
  theme_classic()
asv_histogram
```
