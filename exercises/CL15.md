## Introduction

The package ggplot2 is based on the grammar of graphics ([Wilkinson 2025](https://doi.org/10.1007/978-3-642-21551-3_13)), which is a series of “rules” for creating virtually all graphical forms. It takes a layered approach to creating visualizations. The basic format involves specifying data, aesthetic mapping (i.e., how variables will be represented in the visual space), a coordinate system, and various layers including "geoms" (visual objects), scales, and so forth. In this lab, we will focus on using ggplot2 to create four types of graphs: a histogram, a scatter plot, a bar plot, and a box plot. However, ggplot2 can be used create numerous other types of graphs, such as density plots, box plots, violin plots, maps, and much more. The lesson will demonstrate the “layered” approach by beginning with the simplest form of a graph and then enhancing it with various changes to the code.

## Histogram

In this section, we will create a histogram of the raw ASV counts. First, we need to reformat the data:

```R
asv_rc.long <- melt(asv_rc.long, id.vars = "ASV", variable.name = "Sample", value.name = "Raw_count")
```

Create a basic plot that only contains the data and the aesthetic mappings. Note that nothing will be displayed because you have not specifed what type of plot you are creating; however, this step can save you a bit of time later:

```R
ggplot(data = asv_rc.long, mapping = aes(x = Raw_count))
```

The next step is to add the geom layer. In ggplot2, layers are added with a `+`:

```R
ggplot(data = asv_rc.long, mapping = aes(x = Raw_count)) +
  geom_histogram()  
```

Adding the geom layer calls a histogram on the variable `Raw_count`, which was specifed as "x" in the previous call. Note that, because the normalized counts vary a lot, the distribution is skewed heavily to the left. We can do a log-transformation to fix it:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram()
```

You can change the appearance of the distribution by adding an argument within `geom_histogram()`. There are two options. First, change the number of bins: 

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(bins = 10)
```

This will adjust the number of bins into which the data are sorted. Alternatively, change the bin width, relative to the scale of the x-axis:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25)
```

This will adjust the width of the bins. Practice varying the number of bins or bin width until you find one that you like best. The default color in ggplot2 is gray, but you shouldn't be limited to that! To search for other R colors go [here](https://r-charts.com/colors). Change the color of the bars to the color you want:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "blue")
```

Note that the argument `fill = "blue"` will make both the bars and their borders blue. However, you may want to make the bars and their borders diferent colors for emphasis:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "blue", color = "black")
```

Try adding a hex code instead of a color name. You can use [this resource](https://htmlcolorcodes.com) for hexcodes:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black")
```

Sometimes you will want to modify the limits of the x and/or y axes. This is a somewhat imprecise process for histograms, but the following example shows how to accomplish this. Keep in mind that the number/width of bins will contribute to how R organizes the x axis. In this example, you will set the lower limit of the x axis to NA, which tells R to set the lower limit according to the data. However, you will set the lower limit of y to 0:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500)
```

To add a title use the `ggtitle()` function:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Distribution of Normalized Counts (Log10 Transformed)")
```

By default, ggplot2 uses the variable names as x and y axis labels. Use the `labs()` function to change these:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Distribution of Normalized Counts (Log10 Transformed)") +
  labs(x = "Normalized Counts (Log10)", y = "Frequency") 
```

With a bit of tweaking to the title, you can remove the now-redundant x and y axis labels. Accomplish this by specifying the element_blank() function:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank())
```

You can add notes to parts of the plot by specifying the text and coordinates using the `annotate()` function:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 4), y = c(100, 100), label = c("Rare", "Abundant")) 
```

The ggplot2 package contains several “themes” that allow for quick alterations to the default plot. Try modifying the plot you have just created by adding the `theme_classic()` layer:

```R
ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 4), y = c(100, 100), label = c("Rare", "Abundant")) +
  theme_classic()
```

Feel free to try other themes. Learn more about them [here](https://ggplot2-book.org/themes.html).

Save the final plot as `asv_rc.histogram`:

```R
asv_rc.histogram <- ggplot(data = asv_rc.long, mapping = aes(x = log10(Raw_count))) +
  geom_histogram(binwidth = 0.25, fill = "0099F8", color = "black") +
  xlim(NA, 4) + ylim(0, 1500) +
  ggtitle("Frequency of Normalized Counts (Log10 Transformed)") +
  labs(x = element_blank(), y = element_blank()) +
  annotate("text", x = c(-1, 4), y = c(100, 100), label = c("Rare", "Abundant")) +
  theme_classic()
asv_rc.histogram
```

## Scatter Plot

One of the most common plots in data science is the scatter plot, which examines the relationship between two continuous variables. In this exercise, we will explore whether there is a linear relationship between ASV raw and normalized counts. To do this, we need to reformat the count data:

```R
asv_nc.long <- melt(asv_nc, id.vars = "ASV", variable.name = "Sample", value.name = "Normalized_count")
asv_counts <- merge(asv_rc.long, asv_nc.long, by = c("ASV", "Sample"),  sort = F)
```

Create the basic plot:

```R
ggplot(asv_counts, aes(x = Raw_count, y = Normalized_count)) +
  geom_point()
```

The plot shows an apparent relationship between the raw and normalized counts. However, it looks like we need to log-transform once again:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count))) +
  geom_point()
```

To deal with the issue of overplottingm, we can use the argument `alpha` to make the points lighter or darker. The argument `alpha` can be set as a decimal anywhere between 0 and 1, with smaller numbers indicating lighter points. Try adjusting the alpha value:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count))) +
  geom_point(alpha = 0.1)
```

Notice that some of the points are darker, indicating multiple overlapping data points. To add the regression line with the best fit for the relationship between x and y, create a geom layer called `geom_smooth()`; the default will include an error band around the line:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count))) +
  geom_point(alpha = 0.1) + geom_smooth(method = "lm")
```

We could make all of the points the same color by passing a color name or hexcode to the argument `fill =` within `geom_point`, but it is often more useful to assign a variable to the color aesthetic:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count), color = Sample)) +
  geom_point(alpha = 0.1)
```

More patterns are becoming evident. We may want to see separate regression lines for each sample depicted on the plot. Note that you can remove the error bands by specifying the `se = FALSE` argument:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count), color = Sample)) +
  geom_point(alpha = 0.1) + geom_smooth(method = "lm", se = FALSE)
```

Although using color and separate lines may be helpful for a variable with multiple levels, it can get chaotic real quick. Fortunately, an alternative exists: small multiples! A great function called `facet_wrap()` will replicate the plot for each level of a specifed variable:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count), color = Sample)) +
  geom_point(alpha = 0.1) + geom_smooth(method = "lm", se = FALSE) +
  facet_wrap(vars(Sample))
```

We can remove the redundant legend by passing the argument `legend.position = "none"` to the `theme()` function:

```R
ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count), color = Sample)) +
  geom_point(alpha = 0.1) + geom_smooth(method = "lm", se = FALSE) +
  facet_wrap(vars(Sample)) + theme(legend.position = "none")
```

Save the final plot as `asv_counts.scatter`:

```R
asv_counts.scatter <- ggplot(asv_counts, aes(x = log10(Raw_count), y = log10(Normalized_count), color = Sample)) +
  geom_point(alpha = 0.1) + geom_smooth(method = "lm", se = FALSE) +
  facet_wrap(vars(Sample)) + theme(legend.position = "none")
asv_counts.scatter
```

## Box Plot

We have explored plotting the distribution of a single variable (histogram), two continuous variables (scatter plot), and two continuous variables in relationship to a categorical variable (scatter plot with color and small multiples). What if we want to see the diference between two or more levels of a categorical variable in terms of a continuous variable? For example, we want to know whether median ASV normalized counts and their variability differ by sample. One option is to create a box plot:

```R
ggplot(asv_counts, aes(x = Sample, y = Normalized_count)) +
  geom_boxplot()
```

Log-transform the y-axi values:

```R
ggplot(asv_counts, aes(x = Sample, y = log10(Normalized_count))) +
  geom_boxplot()
```

By default, boxes are ordered alphabetically based on the value of x. However, sometimes we want them ordered in a specifc way. One option is to convert the x variable to a factor:

```R
asv_counts$Sample <- factor(asv_counts$Sample, levels = c("R1A", "R1B", "R2", "R3", "R4", "R5", "R6", "R7", "R8", "R9", "R10", "R11", "R11BF", "R12", "B1", "B2", "B3", "B4", "BW1", "BW2"))
ggplot(asv_counts, aes(x = Sample, y = log10(Normalized_count))) +
  geom_boxplot()
```

Sometimes the values on the x-axis become overcrowded. A solution is to flip the coordinates so that the categorical variable appears on the y-axis and the continuous variable on the x-axis:

```R
ggplot(asv_counts, aes(x = Sample, y = log10(Normalized_count))) +
  geom_boxplot() + coord_flip()
```

Note that you may need to adjust the order of the categorical variable levels by passing the argument `limits = rev` to the function `scale_x_discrete()`. This will ensure that the first factor appears at the top of the y scale:

```R
ggplot(asv_counts, aes(x = Sample, y = log10(Normalized_count))) +
  geom_boxplot() + coord_flip() + scale_x_discrete(limits = rev)
```

Save the final plot as `asv_nc.boxplot`:

```R
asv_nc.boxplot <- ggplot(asv_counts, aes(x = Sample, y = log10(Normalized_count))) +
  geom_boxplot() + coord_flip() + scale_x_discrete(limits = rev)
asv_nc.boxplot
```

Export the box plot as a PDF file; we will use it tomorrow.
