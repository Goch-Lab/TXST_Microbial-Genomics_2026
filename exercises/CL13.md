# Functional Profiling with HUMAnN3

Functional profiling can be done with [HUMAnN](https://huttenhower.sph.harvard.edu/humann/) (<ins>H</ins>MP <ins>U</ins>nified <ins>M</ins>etabolic <ins>An</ins>alysis <ins>N</ins>etwork). HUMAnN is a tool to profile the abundance of microbial metabolic pathways and other molecular functions from metagenomic or metatranscriptomic sequencing data.  However, due to very large database requirements, we will not be running any HUMAnN commands today.

DO NOT RUN THESE! If you wanted to try the example commands out, you could install HUMANn3 with conda and run it with the following commands on LEAP2:

```bash
conda create -n humann3 -c bioconda humann
conda activate humann3

# runn humman3
humann3 --input file.fastq --output output --threads <threads>

# join all output tables (can do for both gene and pathways)
humann_join_tables -i output/ -o genefamilies_joined.tsv --file_name unmapped_genefamilies

# normalize the output (here by tss - total sum scaling, can do for both gene and pathways)
humann_renorm_table --input genefamilies_joined.tsv --output genefamilies_joined_cpm.tsv --units tss

# regroup the table to combine gene families (standardize gene family IDs across taxa)
humann_regroup_table --input genefamilies_joined_cpm.tsv --output genefamilies_joined_cpm_ur90rxn.tsv --groups uniref90_rxn

# give the gene families names
humann_rename_table --input genefamilies_joined_cpm_ur90rxn.tsv --output genefamilies_joined_cpm_ur90rxn_names.tsv -n metacyc-rxn

conda deactivate
```

## Preparing Working Environment and Data

The data we will use in this session is from [Velsko et al. (2022)](https://doi.org/10.1093/pnasnexus/pgac148). They tried to find associations between dental pathologies and taxonomic and genome content. They had a large skeletal collection from a single site in the Netherlands, with a lot of osteological metadata. The study aimed to see if there were any links between the oral microbiome and groups of dental pathologies.

To analyze pre-generated functional profiles using HUMAnN, we will work on RStudio. Create a directory called `functional_profiling` in your local computer. ## Samples Clustering

Let's prepare the data (clean sample names, remove samples with no metadata, etc.), normalize (using a "centered-log-ratio" transformations), for <ins>P</ins>rincipal <ins>C</ins>omponent <ins>A</ins>nalysis (PCA):

```R
# clean data for PCA
humann3_path_l1 <- humann3_path
humann3_path_l1 <- humann3_path[!grepl("\\|", humann3_path$Pathway), ]
little_metadata <- c("MID025.A0101", "MID033.A0101", "MID052.A0101", "MID056.A0101", "MID065.A0101", "MID068.A0101", "MID076.A0101", "MID078.A0101")
humann3_path_l1 <- humann3_path_l1[, !(names(humann3_path_l1) %in% little_metadata)]
poorly_preserved <- c("MID024.A0101","MID063.A0101","MID092.A0101")
humann3_path_l1 <- humann3_path_l1[, !(names(humann3_path_l1) %in% poorly_preserved)]
humann3_path_l1 <- humann3_path_l1[, !grepl("EXB|LIB", names(humann3_path_l1)), drop = FALSE]
filtered_pathways <- humann3_path_l1$Pathway
humann3_path_l1 <- as.data.frame(t((humann3_path_l1[, 2:ncol(humann3_path_l1)] + 1)))
colnames(humann3_path_l1) <- filtered_pathways
```

Check the scree plot:

```R
# check the number of principal components to retain by tuning the PCA
plot(tune.pca(humann3_path_l1, logratio = 'CLR'))
humann3_all_otu.pca <- pca(humann3_path_l1, ncomp = 3, logratio = 'CLR')
humann3_all_pca_values <- humann3_all_otu.pca$variates$X %>%
  as.data.frame() %>%
  rownames_to_column("Library_ID") %>%
  inner_join(., full_metadata, by = "Library_ID")
```

We can see that the first couple of PCs in the scree plot account for a good chunk of the variation of the dataset. Visualise the PCA with one of the custom functions defined above and color by the pipe notches in the teeth:

```R
# define colors and shapes
pipenotch_colors <- c("#311068", "#C83E73")
pipenotch_shapes <- c(16, 17)

# by minimum number of pipenotches
pipenotch <- plot_pca_cont(humann3_path_l1, "PC1", "PC2","Min_no_Pipe_notches","Pipenotch", 3,"Min. No. Pipe Notches")
pipenotch
```

We can see that there is a slight separation between the groups, but how do we find out which pathways may be driving this pattern? For this, we can generate a PCA bi-plot, which shows the loadings driving the spread of the samples:

```R
biplot <- plot_pca_bi(humann3_all_otu.pca, "PC1", "PC2", "Pipenotch", PC1)
biplot
```

From the biplot we can see which pathways are differentiating samples along PC1. We can pull these IDs to find out what pathways they are from the biplot object itself:

```R
# make and save a table of the main pathways
humann3_pathway_biplot_pos <- biplot$plot_env$pws_10
humann3_pathway_biplot_pos <- humann3_pathway_biplot_pos[order(-humann3_pathway_biplot_pos$PC1), ]
humann3_pathway_biplot_pos <- humann3_pathway_biplot_pos[ , 1:3]
humann3_pathway_biplot_pos$Direction <- rep("PC1+", nrow(humann3_pathway_biplot_pos))

humann3_pathway_biplot_neg <- biplot$plot_env$neg_10
humann3_pathway_biplot_neg <- humann3_pathway_biplot_neg[order(-humann3_pathway_biplot_neg$PC1), ]
humann3_pathway_biplot_neg <- humann3_pathway_biplot_neg[ , 1:3]
humann3_pathway_biplot_neg$Direction <- rep("PC1-", nrow(humann3_pathway_biplot_neg))

humann3_pathway_biplot_list <- rbind(humann3_pathway_biplot_pos, humann3_pathway_biplot_neg)
write.table(humann3_pathway_biplot_list, "humann3_pathway_biplot_list.tsv", sep = "\t", quote = F, row.names = F)
```
